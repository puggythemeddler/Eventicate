## Remaining Priority Issues

### [P1] Accessibility debt on interactive components
`Autocomplete.tsx` implements a combobox with no `role="combobox"`/`listbox`/`option`, no `aria-expanded`, no `aria-activedescendant`. Payment modal in `provider/subscription` has no `role="dialog"`, focus trap, or Escape handler. Icon-only buttons (cart qty +/- , delete) lack `aria-label`. `Input.tsx` does not set `aria-invalid` when errored. Sidebar links have no explicit `focus-visible` styling (Tailwind default applies).

**Fix**: Add ARIA roles to Autocomplete, dialog semantics to modals, aria-labels to icon-only controls.

### [P1] Search UX
Search reads `?category=` on mount but doesn't write back when filters change (shareability / back-button loss). Every keystroke triggers a fetch with no debounce. Fetch failures collapse into the empty state — can't distinguish "no results" from "API down".

**Fix**: Debounce input, sync filter state to URL, and surface error state distinctly from empty state.
